# Counterflux — Definitive Feature Audit

*A premium, desktop-first, local-first MTG command centre for one household. Audited against Moxfield, Archidekt, Deckbox, ManaBox, EDHREC, Commander Spellbook, TopDecked, MTGGoldfish, MTGStocks, Scryfall, EDHStats, Playgroup.gg, Lotus/Lifetap, and the 2025-26 calculator ecosystem (ScrollVault, Spellweave, theexpectedvalue.com, etc.).*

## Executive Summary

Counterflux is, on the merits of what it already ships, a genuinely impressive single-household MTG command centre. Its breadth — collection, deckbuilding, market intel, game tracking, AI brewing — and its local-first/offline architecture put it ahead of any single competitor on **integration**. The AI Brewing layer (server-validated candidate pools, no-hallucination guard, multi-turn Mila chat, daily upgrade-scan cron) is arguably best-in-class versus Karn, EDHGen, and farseek. The visual identity and the "interconnected data layer" premise are real, defensible differentiators.

But a consistent pattern runs through every area: **Counterflux has built the hard plumbing and then stopped one step short of cashing it in.** The data already lives locally — `produced_mana`, `oracle_text`, the full price map (`eur`/`eur_foil`/`usd`/`usd_foil`/`tix`), `deck_cards`, the RAG gap-detection output, `is_first`, `unownedPrice`, cheapest-printing resolution — but the *surfaces* that would turn that data into competitor-beating features are missing or shallow.

The gaps cluster into three themes:

1. **Missing flagship 2025-26 features.** No Commander Bracket / Game Changers detection *anywhere* (the strongest competitor precedent in the field). No playtesting/goldfish hand simulator (every major builder has one). No Scryfall search syntax on the local path (the universal power-search language — which the app *accepts during the boot window* then silently degrades).
2. **The "interconnected data layer" promise is partly unrealised.** The Game Tracker never reads the selected deck's commander (logging `null` and quietly corrupting win-rate-by-commander stats *today* — an active correctness bug). No "which decks use this card" reverse lookup. No cross-deck shortfall buy-list. The AI brewer is never told the deck's own computed analytics.
3. **Data-trust & durability rough edges.** No whole-archive backup/restore (catastrophic for an anonymous, browser-only app). CSV import silently drops unresolved rows. Price alerts only fire when you happen to open one screen.

Against the field, Counterflux's position is **"broader than anyone, deeper than no one — yet."** The standing constraints (household-only, desktop-first, local-first) are an asset: they cleanly rule out the social/sharing arms race Moxfield and Archidekt are fighting, and they make several *differentiated* features (server-side budget hard-filtering, auto-snapshot before AI commits, allocated-vs-free copy accounting, "decks containing card X") uniquely cheap. The highest-leverage work is overwhelmingly small-to-medium effort that **surfaces data the app already holds** — and the roadmap front-loads exactly those wins.

### Cross-cutting de-duplications

Several findings recurred across areas and have been merged into a single home:

- **Scryfall search syntax** appeared in both Deck Builder and Platform/global-search. Treated as one parser shared by both paths; the cleanest framing is *"make the local path consistent with the REST path"* (it already accepts syntax pre-bulk-load, then degrades).
- **Commander Bracket / Game Changers** appeared in both Deck Builder and Intelligence. Consolidated into one BRACKET panel that owns *all* bracket logic — including the bracket-aware threshold shifts and over-threshold warnings pulled out of gap-detection.
- **Deck snapshots / version history** appeared in both Deck Builder and Platform. One local-only `deck_snapshots` table, anchored to the AI-commit path as the differentiator.
- **Buy-list / price-to-finish / shortfall** spanned AI Brewing and Collection. One pricing engine (`unownedPrice` + `findCheapestLegalPrinting`), two surfaces (brew review payoff + collection-wide TO-ACQUIRE).
- **First-player / seat stats** were stated twice (a standalone "spinner result unused" finding + the shallow-stats finding). Merged: `is_first` drives both the "on the play" board display and the seat win-rate stat.
- **Collection schema v12** (condition/language/finish/purchase-price) is the **keystone** gating cost-basis P&L, lossless CSV round-trip, and value-over-time. Sequence it before those three.

## Prioritisation logic

Items were ranked by **value × (1/effort) × product-fit**, with three tie-breakers that pushed work up the list: (1) **correctness bugs** masquerading as gaps (the Game Tracker commander resolution and the Movers/24h/alert defects) — these are quietly producing *wrong data today*; (2) **data already in memory/on disk** that just needs surfacing (analytics injection, produced_mana, USD, unownedPrice, is_first) — disproportionately cheap; (3) **constraint-aligned differentiators** the competitors *can't* easily copy (server-side budget hard-filter, auto-snapshot before AI commits, allocated-vs-free copies, "decks containing card X").

**Explicit constraint conflicts surfaced (not silently dropped):**
- *Public deck sharing / social primers / pod sync / shareable recaps / trade matching* → conflict with **household-only, no-public-signup**. Cut or reframed as private/local-only.
- *Background price-push notifications* → conflict with **local-first, anonymous-first** (no server push). Reframed as "alerts evaluated at app open" honest copy.
- *Currency selector* → conflicts with the **deliberate GBP-only** decision. Dropped from the Settings finding.
- *Mobile-first features* → only **Vandalblast** is sanctioned mobile; rotation/tap-zones live there, everything else stays desktop-first.
- *Heavy frameworks* (rich-text primer editor, full rules-engine playtester, recommender ML) → conflict with **vanilla Alpine + Dexie**. Scoped down to plain textarea, hand/zone-only goldfish, and a per-commander reject-list respectively.

**Doc-drift flag:** `CLAUDE.md` lists "deck folders/landing" as shipped — only the landing exists. Worth correcting the brief alongside building the folders.
