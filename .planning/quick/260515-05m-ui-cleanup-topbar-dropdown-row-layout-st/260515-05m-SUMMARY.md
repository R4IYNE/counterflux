# Quick Task 260515-05m — UI Cleanup

## One-liner

Topbar search dropdown rows restructured to a grid layout with proper visual rhythm; add-to-collection panel title + action row now sticky-pinned above the scrolling form; Treasure Cruise heading renamed from "Archive Manifest".

## What changed

### `index.html` — topbar search dropdown row layout

Each result row switched from `display: flex` (4 flex children competing for space) to `display: grid; grid-template-columns: 40px 1fr auto auto;` for predictable column sizing. Thumbnail enlarged 32×32 → 40×56 (MTG card aspect). Name typography switched from JetBrains Mono uppercase 11px to Space Grotesk 14px — natural card-name reading. Added secondary line under each name showing `SET · #COLLECTOR_NUMBER` in 10px JetBrains Mono. Row separator borders (`border-bottom: 1px solid var(--color-border-ghost)`) give visual rhythm. Min row height 60px prevents collapse on broken-image fallback.

### `src/components/add-card-panel.js` — sticky panel header

Split the panel into a fixed-size `<div class="tc-panel-header">` (title + chevron close + BROWSE PRECONS / MASS ENTRY action row) and the existing scrollable `<div class="tc-panel-body">`. The header is a `flex-shrink: 0` flex-column child of the aside; the body is `flex: 1; min-height: 0; overflow-y: auto;`. Title and action row stay visible regardless of how far the user scrolls into selected-card preview / printings strip / qty / foil / category / action buttons.

FOLLOWUP-1 invariant from Phase 08.1 preserved: aside still has `overflow: visible` so the absolutely-positioned search dropdown escapes its content box; body still owns its own `overflow-y: auto`.

### `src/screens/treasure-cruise.js` — heading rename

Line 63: `Archive Manifest` → `Treasure Cruise`. Subheading "MASTER REPOSITORY SUMMARY" unchanged.

### Test updates

- `tests/router.test.js` — heading test description + assertion updated to `Treasure Cruise`.
- `tests/add-card-panel.dropdown.test.js` — FOLLOWUP-1's "body opens before header" test was locking the old structure; replaced with two assertions covering the new pattern: (1) header opens before body, title sits between them (= title in header, not body); (2) header has `flex-shrink: 0` + explicit `background: var(--color-surface)` so it pins above the scrolling body.
