# Quick Task 260515-05m — UI Cleanup

## Goal

Three small UX wins surfaced during user feedback on the load-perf fix screenshot:

1. **Topbar search dropdown layout** — screenshot showed cramped rows with no separation; restructure for visual rhythm and reliable column sizing.
2. **Sticky add-to-collection panel header** — when the Treasure Cruise add panel content overflows (selected card preview + printings strip + qty/foil/category/action buttons), the panel title + chevron close + action row scroll out of view. Make them pin to the top of the panel.
3. **Rename Archive Manifest → Treasure Cruise** — terminology alignment per user request.

## Tasks

### Task 1 — Topbar dropdown row layout (index.html)

Restructure each search row from `display: flex; align-items: center;` (4 flex children competing for space) to `display: grid; grid-template-columns: 40px 1fr auto auto;` for predictable column sizing.

Changes:
- Thumbnail: 32×32 → 40×56 (matches MTG card aspect ratio, art actually readable)
- Name typography: JetBrains Mono uppercase 11px → Space Grotesk 14px (sentence case — natural card-name reading)
- Add secondary line below name: `[SET CODE] · #[COLLECTOR_NUMBER]` in 10px JetBrains Mono uppercase
- Row separator: `border-bottom: 1px solid var(--color-border-ghost)` for visual rhythm
- Min row height: 60px → no collapse when image fails to load
- Mana cost: explicit `font-size: 12px; line-height: 1;` to constrain mana-font icons

### Task 2 — Sticky panel header (src/components/add-card-panel.js)

Split `<aside class="tc-panel-column">` into two regions:

- `<div class="tc-panel-header">` — `flex-shrink: 0`, padding 24px 24px 16px, `background: var(--color-surface)`, `border-bottom: 1px solid var(--color-border-ghost)`. Contains title row (ADD TO COLLECTION + chevron close) and action row (BROWSE PRECONS + MASS ENTRY).
- `<div class="tc-panel-body">` — unchanged `flex: 1; min-height: 0; overflow-y: auto;` semantics. Contains search input + selected card preview + printings + qty/foil/category/action buttons.

The aside remains a flex-column with `overflow: visible` (FOLLOWUP-1 invariant from Phase 08.1 preserved — dropdown still escapes content box). The header naturally pins to the top because it's a fixed-size flex child above the scrolling body.

### Task 3 — Archive Manifest → Treasure Cruise (src/screens/treasure-cruise.js)

Single string replacement at line 63 in the screen heading. Subheading "MASTER REPOSITORY SUMMARY" unchanged.

### Test updates

- `tests/router.test.js` — `treasure-cruise shows "Archive Manifest" heading` → `shows "Treasure Cruise" heading`.
- `tests/add-card-panel.dropdown.test.js` (FOLLOWUP-1 suite) — the test asserting `tc-panel-body` opens before the header row was locking the old "header inside scroll region" structure. Replaced with two assertions:
  1. Header opens before body, title text appears between header-open and body-open (i.e. title lives in header, not body).
  2. Header has `flex-shrink: 0` + explicit background so it pins above the scrolling body.
